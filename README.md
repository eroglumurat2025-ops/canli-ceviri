# Canlı Çeviri

Telefon tarayıcısında çalışan, sürekli dinleyen canlı çeviri uygulaması. Konuşmayı telefonun ses tanıma özelliğiyle yazıya döker, Claude ile çevirir ve sesli okur.

- Diller: Türkçe, İngilizce, Fransızca, Çince, Almanca, İspanyolca, Arapça, Rusça; uygulama içinden yeni dil eklenebilir.
- Çeviri için bir Claude API anahtarı gerekir (console.anthropic.com). Anahtar yalnızca telefonda saklanır.
- İnternet bağlantısı gerektirir.
